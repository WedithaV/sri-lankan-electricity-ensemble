# AI Usage Declaration

**AI tool used:** Claude Code (Anthropic), model Claude Opus 5.5, running in VS Code.

**Period of use:** 23–24 November 2026.

## How I used AI in this project

The idea, plan and direction of this project are mine. I chose the RECON-SL Sri Lankan electricity dataset, defined
the prediction problem (next month's household electricity consumption), and planned the work: which models to
compare (baselines, Bagging, Boosting, Voting and Stacking), how to evaluate them fairly over time without data
leakage, what the dashboard should show, and how it should look.

I used Claude Code as an assistant to help me carry out this plan. **The program code, notebooks, dashboard code,
tests and first drafts of the documentation were generated with AI**, following my instructions. I worked through
the project phase by phase: at each stage the AI presented the evidence and options, I made the decisions, and I
reviewed the results before moving on. Where I disagreed with a suggestion, I changed it.

I did not accept the AI's output blindly. I required every important assumption to be checked against evidence,
asked for automated tests to catch mistakes and data leakage, and required that every number and chart come from
code that was actually run, with nothing invented.
